# Issue tracker

## Backend

This repository tracks work in GitHub Issues for [`madheu/qiming`](https://github.com/madheu/qiming). Use the `gh` CLI (or the GitHub web UI) to read and write issues.

## PRs as a request surface

**Off by default.** Pull requests are not added to the triage queue unless this setting is deliberately changed.

## Operational notes

- Keep issue state and discussion in GitHub rather than creating local issue files.
- Use the repository's canonical labels; do not add labels merely because a skill suggests them unless they are part of the documented vocabulary.
