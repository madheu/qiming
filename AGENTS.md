# Agent skills

## Issue tracker

GitHub Issues for `madheu/qiming` (use `gh issue`); PRs are not a request surface by default. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels are `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. Wayfinder labels are `wayfinder:map`, `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling`, and `wayfinder:task`. See `docs/agents/triage-labels.md`.
